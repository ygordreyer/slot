Slot adaptations for the 720x480 panel (GBA at exactly 3x):
- handheld/shaders/mgba/agb001.glsl and ags001.glsl retain their MPL-2.0
  notices. LCD_SCALE selects three RGB columns or the upstream four-column
  RGB/grey mask, with the dark row at the end of the selected cell.
  MASK_STRENGTH mixes the mask with white. Source defaults retain the
  upstream four-column/full-strength look; recipes select 3 and 0.35.
- handheld/agb001-gba-color-motionblur.glslp,
  handheld/ags001-gba-color-motionblur.glslp and handheld/ags001.glslp:
  mGBA scale 3.0, nearest filtering throughout, 1:1 viewport finish.
  The color-motionblur recipes set darken_screen=0 to avoid adding the
  GBA color pass's extra darkening to mGBA's existing gamma curve.
  Both AGS recipes set lightBrightness=0.5 to reduce the blue-grey
  frontlight veil. These strength/light defaults need device validation.
- handheld/bevel.glslp: BEVEL_LEVEL=0 keeps black pixels black while
  retaining the bevel computed from non-black source colors.
- handheld/zfast-lcd.glslp: GBAGAMMA=0 removes the extra GBA darkening
  curve; BORDERMULT=14 retains the upstream border mask.
- Removed handheld/dot (duplicates the LCD grid at fixed 3x) and
  interpolation/sharp-bilinear (a no-op at fixed 3x), including their
  unshared pass sources. The bundle now contains 11 presets.

Cost estimates, not device timings. Output is GBA 240x160 to 720x480.
Fetches count texture sampling instructions per output pixel per pass,
not individual texels fetched by bilinear hardware. Final explicit scales
also require one 720x480 copy pass (one fetch per pixel), listed as +copy.
Source history needs one retained 240x160 frame upload per source update.
Reference budget: lcd-grid-v2-gba-color-motionblur = 8@240x160,
4@720x480, 1@720x480, +copy = 2,380,800 sampling instructions/frame.
Limit is approximately 4,761,600 instructions/frame. ALU-heavy effects
need device verification even when this bandwidth estimate fits.
