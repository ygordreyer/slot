Reference fixture generator (from repository root):
  python3 crates/slot/tests/audio_reference.py --golden
Requires cc and the supplied reference copies in target/ref/ra-audio/.
The generator compiles those copies directly, supplies minimal ABI headers, and
uses their float processing entry points with SIMD disabled and FP contraction off.
No int16 reference path is used. FFT is included by eq.c.
Fixtures: crates/slot/tests/fixtures/audio/*.f32le, little endian IEEE f32 stereo.
Each DSP fixture uses 4096 frames of swept sine plus deterministic LCG noise at
32768 Hz. Sinc HIGHER outputs 48000 Hz, with a separate +0.4% ratio change halfway.
The live equivalence check uses 8192 input frames:
  python3 crates/slot/tests/audio_reference.py
  cargo test --offline -p slot --test audio_look reference_live_equivalence -- --ignored --nocapture
Host benchmark:
  cargo test --offline --release -p slot --test audio_look benchmark_ten_seconds -- --ignored --nocapture
